# whoops for Craft CMS 4/5

whoops error handling for Craft CMS.

![Screenshot](resources/whoops.png)

## Requirements

This plugin requires Craft CMS 4.0.0 or later.

## Installation

`composer require cloudgrayau/whoops`

## whoops Overview

Replaces the default error handling in Craft CMS with whoops (PHP errors for cool kids). This will only occur whilst `DEV mode` is enabled for security reasons.
